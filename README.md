# 🚗 Car Price Prediction using Machine Learning

This project predicts the selling price of a used car using a Random Forest Regressor.

# 📌 Project Overview
The model is trained on car features such as:
- Present Price
- Kms Driven
- Fuel Type
- Seller Type
- Transmission
- Car Age

The model predicts the **Selling Price of a Car in Lakhs**.

## 🧠 Machine Learning Algorithm
Random Forest Regressor (Supervised Learning - Regression)

## 📂 Dataset
Car Dataset contains:
- Car_Name
- Year
- Selling_Price
- Present_Price
- Kms_Driven
- Fuel_Type
- Seller_Type
- Transmission
- Owner

## ⚙️ Steps Performed
1. Data Cleaning & Preprocessing
2. Feature Engineering (Year → Car Age)
3. One Hot Encoding
4. Train-Test Split
5. Model Training (Random Forest)
6. Model Evaluation (R2 Score)
7. Price Prediction
